Courses · Six-Month Courses

Two six-month courses. One ends on Demo Day, the other at the Tech Expo.

Both run five live sessions a week, one hour each, never more than five children in the class — about 120 sessions over six months. Your child is placed by age and by what they can already do, not by a form.

HOW EVERY CLASS RUNS

We never open with “today we will learn lists.”

We open with a problem — build a restaurant ordering system — and the programming concepts arrive only when a child needs them to solve it. Nine steps, every session, both courses.

01
Real-world problem The trainer opens with something worth building.
02
Student discussion Children argue for their own approach first.
03
Algorithm design Written in plain language before any code.
04
Choose the concepts They name the loop, list or function needed.
05
Write the AI prompt A structured prompt, not a vague question.
06
Generate the code With academy-managed keys and supervision.
07
Explain every line Nothing is submitted that cannot be explained.
08
Improve the solution Beyond what the model produced.
09
Present the project Out loud, to the class, every session.
NOT EXAMS — WHAT WE ACTUALLY ASSESS

No child submits AI-generated code they cannot explain. Trainers hold every API key, children never paste personal data into a model, and each project is judged on six things.

Problem analysis Algorithm design Prompt quality Code understanding Code improvement Presentation

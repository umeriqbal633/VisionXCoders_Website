Course Overview

What your teen will build in Tech Builder

Tech Builder is a six-month course for teens ready to move beyond the basics. It deepens Python into real projects, teaches object-oriented programming through games, moves into AI APIs and automation tools, and finishes with a capstone your teen presents at their own booth on Tech Expo day. Classes run five times a week, one hour each, in small groups of no more than five children.

What Your Teen Will Learn

Real tools, real projects

🐍

Professional Python

File handling, modules, libraries, and exception handling — built as an attendance system, password manager, and expense tracker.

🧱

Object-Oriented Programming

Classes and objects taught through games: Snake, Brick Breaker, Maze Escape, and an inventory system.

🎮

Game Development

One game of their choosing — animation, collision, game states, menus, lives, levels, and sound.

🤖

Artificial Intelligence

Prompt engineering, responsible AI, AI APIs, chatbots and voice — a homework helper, study buddy, and quiz generator.

🚀

Automation & Productivity

A folder organiser, PDF report and invoice generators, an email assistant, and a reminder system.

📊

Data Structures

Organize and work with data the way a real software engineer would.

🎤

Tech Expo Presentation

Present a finished capstone project live, at their own booth, to an audience.

⚖️

Responsible AI Use

Trainers hold every API key; every project is judged on whether the student can explain it, not just run it.
